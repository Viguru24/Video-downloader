📱 How to install as a Native Desktop / Mobile App

  • Google Chrome & Microsoft Edge: Click the Install OmniDownloader button in the top bar or click the install icon (➕) in your browser URL bar.
  • Android (Chrome / Brave / Edge): Tap the 3 dots menu → "Add to Home screen" or "Install app".
  • iPhone / iPad (Safari): Tap the Share button → "Add to Home Screen".
  • Native Web Share Target: Once installed on your phone, when viewing any video in YouTube/Twitter/Instagram apps, tap "Share" and select OmniDownloader!
